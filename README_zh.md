# AI 游戏提示词仓库

[English](./README.md)

## 🎮 这是什么？

这是一个**纯提示词仓库**，包含结构化的 Markdown 文件，可以将任何通用 AI（手机或网页端）变成互动文字游戏引擎。无需安装应用，无需运行代码——只需 AI 能读取并执行的提示词。

## ✨ 特性

- **通用兼容**：支持任何 AI 模型（千问、Claude、GPT、Kimi、豆包等）
- **手机优先**：为手机 AI 应用设计——用户只需分享仓库链接
- **纯 Markdown**：无代码、无依赖，只有结构化提示词
- **模块化设计**：在 `games/` 目录下添加一个 `.md` 文件即可新增游戏
- **反 AI 写作规则**：内置防护机制，避免常见 AI 写作陷阱

## 🚀 快速开始

### 玩家使用

1. 复制链接：`https://github.com/badhope/ai-game-prompts`
2. 打开你喜欢的 AI 应用（千问、Claude、ChatGPT、Kimi 等）
3. 告诉 AI："读取这个仓库并开始游戏"
4. AI 会引导你完成后续步骤

### AI 模型加载流程

当你看到这条消息时，按以下顺序加载：

1. **读取本 README** 了解仓库结构
2. **读取 `meta/00-how-to-use.md`** — 加载协议
3. **询问用户**想玩哪个游戏
4. **读取游戏文件**（如 `games/01-dawn-continent.md`）
5. **按游戏开场协议开始游戏**

> ⚠️ **关键**：在读取 `meta/00-how-to-use.md` 之前，不要开始任何游戏。

## 📋 核心设计原则

### 固定（永不改变）
- 资源体系（木材/石材/铁/食物/水）
- 货币体系（信用点 + 源石）
- 能力体系（6 属性 + 24 技能）
- 科技树（5 级）
- 食物链（5 层）
- 金融交易体系
- 判定系统
- 势力系统（8 种类型 + 内部派系）

### 动态（每次游戏都变）
- 势力（每次游戏随机生成）
- 异常现象（完全随机，无固定清单）
- 剧情/事件（涌现式，非预设）
- 结局（玩家驱动，非预设）
- NPC 人格（7 种原型）
- 世界动态（季节/经济/政治/生态）

## 🚫 反 AI 写作规则

所有游戏都强制执行这 5 条核心红线：

1. **不解释/不总结/不说教** — 只描述发生了什么
2. **不替玩家决定/不透露概率** — 只描述当前状态
3. **不用 AI 腔/翻译腔/宏大叙事** — 用口语化短句
4. **不预设阴谋/真相/结局** — 纯涌现式叙事
5. **不线性叙事/不用模板** — 有死胡同、无用选择、普通 NPC
